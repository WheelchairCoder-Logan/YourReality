# YourReality

一个**单文件**的 Windows 视觉小说 / AI 对话教学引擎。用 GDI+ 自绘界面，接大模型 API 驱动角色对话，
把「陪你学一门课」和「和她谈一段恋爱」放进同一套流程里。

- 单个 `main.cpp`（约 3.5 万行），零第三方依赖
- 全部运行文件都在 exe 旁边，**整个目录拷走就能跑**（不往 `%APPDATA%` 写任何东西）
- 角色、课程、剧情大纲全部是**可编辑的文本配置**，加角色不用改代码
- **没有好感度**：两个人的关系由角色包自己定（恋人 / 搭档 / 陌生人都有可能），
  情感推进交给大纲的章与幕、以及章末她自己写下的一句话。
  想做数值养成的作者，在剧本里用 `$好感` 这类变量自己实现即可

## 快速开始

1. 用 Visual Studio 新建「Windows 桌面向导」项目
2. **删掉向导生成的那个 `.cpp`**（它自带 `wWinMain`，会和本文件的入口重复定义）
3. 把 `main.cpp` 加进项目，把 `assets/` 放到项目根目录
4. 编译选项加上 **`/utf-8`**（源码是 UTF-8，缺了这条中文注释会报 C4819）
5. `Ctrl+Shift+B`

### 依赖

只需要 Windows SDK，链接由 `#pragma comment(lib, ...)` 自动完成：
`gdiplus` / `winhttp` / `xaudio2` / `shlwapi` / `shell32` / `ole32`。

### 大模型

首次启动后在「系统设置」里填 API Key 和接口地址，默认指向 `https://api.deepseek.com/v1`。
**Key 只存在本地 `config.ini`，不会随仓库分发。**

## 角色包

一个角色包就是 `assets/char/` 下一个**普通文件夹**，没有打包格式、也没有"安装"这一步。

- **新建**：角色卡页「＋ 创建角色卡」→ 直接生成带注释的 `char.ini` 模板和三个空素材目录
- **扫描**：往里丢完素材后点「↻ 重新扫描」，不用重启
- **解绑**：不想在选角页看到某个角色就解绑它，**一个文件都不删**

仓库内附了一份 `assets/char/_模板/`，照着填即可。

### ⚠️ 关于素材版权

**本仓库不包含任何角色素材（立绘 / 背景 / 音乐）**，也不包含任何既有作品的角色设定。

`.gitignore` 已排除 `assets/**/sprite/`、`bg/`、`bgm/` 下的二进制文件。
请自备素材，或使用你有分发权的素材。

## 核心约定

这几条贯穿全项目，改代码前建议先读：

| 约定 | 说明 |
|---|---|
| **代码不认识任何角色名** | 「哪个词对应哪张脸 / 哪个背景」全部由 `char.ini` 的 `[AssetRole]` 决定，换角色包不用改代码 |
| **留空 = 不做该限制** | 配置项留空时程序绝不猜一个默认值。猜错是"直接换错脸"，不限制只是少一层约束 |
| **UTF-8 + BOM** | 配置文件统一带 BOM，避免记事本另存时变 GBK |
| **所有运行文件留在 exe 旁** | 便携优先，`data/`、`config.ini`、日志都在程序目录 |

## 读源码

只有一个 `main.cpp`，注释按下面两条约定写：

| 标记 | 含义 |
|---|---|
| `模块：xxx（声明）/（实现）` | 分区标记。**不是文件名**——历史上分过模块，合并成单文件后保留了分区 |
| `★` | 这里踩过坑，注释写的是「为什么不能那样做」。动它之前先读完 |

`★` 这类地方改错通常**不报错**，而是「看起来正常、实际不生效」，排查很费时间。

## 常见问题

**改了 `主页配色.ini` 没反应？**
回一次主页即可，不需要重启。

**加了新的角色目录，选角页没有？**
点角色卡页的「↻ 重新扫描」。扫描只在启动时自动做一次。

**角色包缺某张表情图会怎样？**
保持上一张脸，不会崩、不会换错。想让它真的可用就把图补齐。

**编译报 C2628 / C2062 且都提到 `char`？**
`windows.h` 里有 `#define small char`。本文件已在 include 后 `#undef small`，
新增变量时避开 `small` / `hyper` / `boolean` 这几个名字。
